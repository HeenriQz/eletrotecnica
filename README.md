# +100 Mapas Visuais de Eletrotécnica

Landing page de vendas do produto digital **"+100 Mapas Visuais de Eletrotécnica"**.

## 🎯 Sobre

Página de conversão otimizada para mobile, focada em velocidade e usabilidade em celulares com conexão lenta.

## ⚡ Características

- **Mobile-first** — otimizada para smartphones
- **Leve** — carrega rápido em conexões 3G/4G
- **Compatível** — funciona em navegadores antigos (ES5)
- **WebP com fallback** — imagens otimizadas (-70% de peso)
- **Lazy loading** — imagens só carregam quando visíveis
- **2 carrosséis em loop** com autoplay e swipe
- **Sticky CTA mobile** — botão fixo de compra no rodapé
- **FAQ accordion** interativo
- **Zero dependências** — só HTML, CSS e JS puro
